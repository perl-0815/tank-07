# 水槽07 — ABYSSAL-7

深度3,200mの海底研究施設と、180秒だけ接続できるチャットADV。
正本はルートの [`UI.txt`](./UI.txt) と [`シナリオ.txt`](./シナリオ.txt)。ほかの作品のファイルは変更せず、独立した Next.js App Router アプリとして実装しています。

## 起動

Node.js 22.13以上、pnpm 10系を使用します。

```sh
git clone https://github.com/perl-0815/tank-07.git
cd tank-07
pnpm install
pnpm dev
```

[http://127.0.0.1:3007](http://127.0.0.1:3007) を開いて「接続を開始」。外部API、環境変数、アカウントは不要です。

本番動作をローカルで確認する場合：

```sh
pnpm build
pnpm start
```

## 実装したゲーム体験

- 会話選択肢と自由なキーワード入力による探索、指示、コード認証。
- 「選択肢を開く」で、その時点で使える応答を一覧表示。会話・電源・調査・施設操作を同じ一覧で選べ、メニューを往復する必要はありません。入力欄を残したまま一覧をスクロールでき、Escapeや選択後に閉じます。
- 選択済みの会話や調査は、淡い色とチェック印で区別し、引き続き選べます。履歴は次周にも持ち越し、設備操作や信頼度は毎周リセット。今周の短い再読では所要時間も2秒と表示します。
- 候補が一覧に収まらないときだけ「下に続き」「上に戻る」を表示。クリックやキーボードでも一覧を送れ、スクロール位置・画面サイズ・候補数に合わせて案内が変わります。
- 180秒から実時間と各行動の所要秒数を減算。タブを離れた間も時間は経過します。
- 正しいキーワードは情報未取得でも有効。全角数字・英字の大文字小文字・空白・代表的な句読点を正規化。
- 重要な攻略候補は必要な記録が揃うと「記録より」と表示。初めてでも探索からボタンだけで進められ、正解を知っていれば直接入力で先回りできます。
- 今回の接続でユナが共有した情報と、過去の接続から持ち越した記録を区別。正規に教わった場所・コードには通常の応答を返し、先回り入力への反応と分けています。
- 「信じて」の候補は表示しません。異なる監視記録を一緒に確認する自然な調査で信頼が回復し、説得を繰り返さず真相ルートへ進めます。同じ記録の再読では信頼は増えません。
- 状況を前提とする応答は、その接続で説明を聞いてから表示。最初は4つの問いかけから始まり、扉の状態・停電・監視映像などを知るにつれて候補が増えます。受信中は一覧を閉じ、台詞より先に候補が見えることを防ぎます。
- 水槽のセンサー・録音、監視記録、通信診断は、会話で調べ方を伝えてから候補化。判明した調査手段は記録に残り、次の周回も設備が使える段階で選べます。扉の状態など、その場の状況は持ち越しません。
- 電源・ポンプ・隔離の操作順序、信頼分岐、調査ルート、時間切れと事故による失敗。
- NORMAL / TRUE / SECRET と、自由入力専用の ECHO の全4エンディング。通常の救出では初周のSECRETを優先。
- TRUEでは3分間の再構築・模倣された声・地上からの言葉のつながりを会話で補足。ユナ本人の行方とUNKNOWNの正体は余韻を残し、ECHOでは引継ぎで何が保存されるかを伝えます。
- 本人確認後はユナが設備状態に合った救出操作へ案内。NORMALでは、残された声・生体反応・監視記録の疑問を次の調査につなげます。
- 自由入力には短い隠し応答と、通信記録から辿れる二段階確認の別ルートを用意。引継ぎの合言葉は候補や入力補完には出さず、知っていれば未取得でも使用できます。
- 通信ログ、取得情報の記録、既読省略、受信の早送り、短い通信断と再接続。
- ログの `+MM:SS` は接続からの経過時間。ヘッダーの残り時間とは区別し、操作にかかった時間も含めて進みます。
- 時間切れ・失敗時は短いノイズと切断モーダルを表示。「再接続する」か「通信ログを見返す」を選べます。画像・記録を開いている最中も切断通知を優先。
- IMG_01〜IMG_10 の受信イベントとキーボード対応の拡大表示。
- CRT走査線、短いグリッチ、警告、控えめなタイプ表示。演出軽減とOSの動き軽減設定に対応。
- 画面全体を使うレイアウト。チャットと入力欄は中央の幅760pxに揃え、スマートフォンでは画面幅に合わせます。タイマーと下部操作は常時表示。
- YOUの送信文は、暗い背景と内側の影を付けたログとして表示。狭い画面でも長文を折り返し、ユナの受信文と区別できます。
- スタート画面で施設の事故・研究員ユナ・3分の通信制限を短く紹介。装飾ラベルを整理し、演出設定は操作案内へ集約。
- モバイルの表示領域の変化に追従。日本語の変換確定Enterと送信Enterを区別します。

画像と記録を開いている間も時計は進みます。攻略完了後の終幕だけは時計を止め、最後の会話を読めるようにしています。音声は実装していません。

## 保存の扱い

`localStorage` の `abyssal-7.memory.v1` に取得情報、接続回数、既読文、選択済みの操作IDを保存します。施設の状態・信頼度・その接続でユナと共有した情報は持ち越しません。ページを再読み込みすると、残った記録から新しい周回を始めます。選択履歴を持たない旧版の保存も引き続き利用でき、履歴だけを未選択から始めます。「操作案内」から確認付きで記録と選択履歴を消去できます。

保存を利用できないブラウザでもそのセッションはプレイでき、端末下部に保存不可を表示します。個人情報、アクセス解析、外部通信は使用しません。

## 編集箇所

| ファイル | 役割 |
| --- | --- |
| `src/game/scenario.ts` | `SCRIPT` 会話本文、`ACTIONS` 消費時間と取得情報、`CHOICE_GROUPS` 候補一覧、`CHOICE_RECORDS` 記録条件、`CHOICE_CONTEXTS` 会話の前提、`SCRIPT_TOPICS` / `ACTION_TOPICS` 共有される話題、`KEYWORDS` 入力候補、`FACTS` 記録 |
| `src/game/free-input.ts` | 候補に出さない隠し応答、引継ぎの二段階入力、消費時間、ECHO ENDの会話 |
| `src/game/engine.ts` | 純粋関数による時間・物理条件・信頼・周回・エンディング判定 |
| `src/game/types.ts` | ゲーム状態・メッセージ・選択肢の型 |
| `src/game/images.ts` | 画像ID・パス・代替文・カメラ名・架空の信号品質 |
| `src/hooks/use-game.ts` | 実時間との同期、端末記録、接続処理 |
| `src/hooks/use-playback.ts` | 受信順序、文字表示、既読スキップ |
| `src/components/terminal.tsx` | 画面、入力、記録と操作案内 |
| `src/components/choice-picker.tsx` | 展開式の候補一覧とキーボード操作 |
| `src/components/attachment.tsx` | 画像添付カード |
| `src/app/globals.css` | 配色・レイアウト・レスポンシブ・演出 |

物理条件は `knownFacts` と分離しています。取得情報で選択肢を補完しても、同じ正解の自由入力を知識フラグで拒否しない設計です。TRUE ENDの真相情報条件だけはシナリオ指定の6情報を使用します。

仕様に取得場面がなかった排水ポンプ停止の手順は、中央管理端末の圧力制御ログと警告に補っています。誤順序で隔離を開くと失敗し、その後にポンプを停止して成功へ変更することはできません。

## 画像の差し替え

提供された画像1〜10を、`public/images/` の用途に対応した英語名で配置しています（例：`research-section-04.webp`、`true-ending-signal.webp`）。原画を画素が変わらないWebPへ変換し、配信時はNext/Imageで最適化しています。通常1672×941px、修正された非常電源端末は1671×941pxです。

差し替える場合は `src/game/images.ts` の `src`、`width`、`height`、`alt` を変更してください。メッセージ内の `imageId`（IMG_01〜IMG_10）はそのまま利用できます。

非常電源端末は静的importを使用し、寸法と内容に応じた画像URLを自動生成します。同名のWebPを差し替えても以前の最適化画像が残らないようにしています。

共有用の12番画像は `src/app/opengraph-image.png` に配置。日本語の説明とともにOpen Graph・Twitter大判カードへ設定しています。公開先は任意の `NEXT_PUBLIC_SITE_URL`（例：`https://your-domain.example`）、Vercelの公開URL、リクエスト元ホストの順で解決します。固定URLを設定しない場合も、公開先で絶対URLの画像メタタグを生成します。
